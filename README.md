# Godnotic update compatibility

This user Pages site preserves installed clients' legacy project Pages paths.
It never rebuilds the game or publishes releases. The main project is
[dixonSolutions/Godnotic](https://github.com/dixonSolutions/Godnotic).

The legacy Flatpak summary redirects clients to the canonical Godnotic remote.
Click metadata points at the canonical packages; old direct latest downloads
remain available. The source repository at the old name is deliberately not
recreated, so GitHub's Git/API redirects to Godnotic keep working.
